# こえそろえ — VOICE LEVELING STUDIO

複数の台詞音声の音量を、まとめてそろえる静的Webアプリです。
**ビルド不要、サーバー不要。GitHub Pagesにそのまま公開できます。**

## 機能

- WAV / MP3のドラッグ＆ドロップ・複数ファイルの追加読み込み
- 声が出ている区間を中心とした平均音量（ゲート付きRMS）の測定
- 目標音量、ピーク上限、最大増幅量の設定
- 元音声と調整後音声の聴き比べ
- 変更前／変更後の波形・ゲイン・平均音量・ピークの表示
- WAV（16-bit PCM）またはMP3（128 / 192 / 256 / 320 kbps）書き出し
- 44,100 Hz / 48,000 Hz 出力、モノラル／ステレオ対応
- 一件ずつのダウンロードと、複数ファイルのZIP一括ダウンロード
- 重複するファイル名の自動連番処理

## 使い方

1. `index.html` をブラウザで開くか、GitHub Pagesの公開URLにアクセスします。
2. WAV / MP3ファイルをドラッグ＆ドロップ、またはクリックして読み込みます。
3. 左側の「目標の声の音量」を設定します。初期値は **-20 dBFS（発声区間RMSの推定値）** です。
4. 各行の「▶ 元」「▶ 調整後」で音量を聴き比べます。
5. WAV / MP3、サンプルレート、必要に応じてMP3ビットレートを選びます。
6. 「↓ 保存」で個別書き出し、または「まとめてZIPで書き出す」で一括保存します。

## GitHub Pagesへの公開

1. GitHubで新規リポジトリを作成します（例: `koesoroe`）。
2. このフォルダの中身を、**リポジトリのルート**へアップロードします。`index.html` がルートにあることが重要です。
3. GitHubリポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source** で `Deploy from a branch` を選択します。
5. **Branch** を `main`、フォルダを `/(root)` にして保存します。
6. GitHub Pagesの公開URL（`https://ユーザー名.github.io/リポジトリ名/`）にアクセスします。

`index.html` / `style.css` / `app.js` / `assets/` / `vendor/` をまとめて配置してください。npmやビルドコマンドは不要です。

## 音量の仕組みと注意点

- 本ツールの測定値は **LUFSではなく、20msごとのRMSを用いた独自の発声区間推定** です。無音区間を除くため、最大20ms区間の音量より30dB以上低い区間、または-55dBFSより低い区間を測定から外します。無音に近い特殊なファイルは全体RMSにフォールバックします。
- ノーマライズには**一定のゲイン**をかけます。コンプレッサーで声の抑揚をつぶしたり、無音部分の長さを削除したりはしません。
- 設定したピーク上限・最大増幅量に達した場合、目標の平均音量に届かないことがあります。その場合は各行に表示されます。
- 表示・制限するピークは**サンプルピーク**です。インターサンプルピーク／MP3の再デコード後のピークは保証されません。音割れが気になる場合はピーク上限を -2 ～ -3 dBFS に下げてください。
- 入力ファイルのサンプルレートはブラウザでデコードされた後、選択した出力レートに変換されます。
- ブラウザ内で音声を保持・処理し、**音声ファイル自体はサーバーに送信しません**。リロードするとリストは消えます。
- 非常に大量／長時間の音声や1ファイル250MB超の音声は、メモリ使用量のため対象外または処理が重くなります。

## MP3書き出しとインターネット接続

WAV出力・ZIP保存はアプリ内のファイルだけで動作します。MP3エンコードは、ページ読み込み時にCDNから **lamejs 1.2.1** を読み込みます（メイン: cdnjs、代替: jsDelivr）。MP3書き出しを行う際はネットワーク接続が必要です。通信制限環境ではWAV出力をご利用ください。

外部通信はこのMP3エンコードライブラリの取得に使われます。選択した音声の送信処理は一切ありません。
